# Pritam Priyabrata Palai — 3D Portfolio

Dark minimalist portfolio with a two-color neon system (cyan + purple), interactive 3D neural brain, project showcase, responsive layouts and live GitHub commit activity.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack

- Next.js + TypeScript
- React Three Fiber + Three.js + Drei
- CSS
- GitHub REST API through a Next.js route
